# 🚆 離我最近 - 台鐵即時列車看板 (TRA Live Board)

一個輕量化、適用於手機瀏覽器的即時台鐵列車看板。透過手機 GPS 定位，自動比對距離目前位置最近的台鐵車站，並顯示即時列車班次與延誤動態。

---

## ✨ 主要功能

* **📍 自動 GPS 定位**：自動取得目前經緯度，並精準計算距離最近的台鐵車站。
* **⏱️ 即時班次資訊**：顯示最近車站未來即將到站/開出的列車班次、車次與目的地。
* **⚠️ 準點/延誤狀態**：即時抓取 TDX 交通部資料，清楚標示列車是否準點或延誤分鐘數。
* **📱 手機最佳化**：針對行動裝置設計的直立式卡片介面，方便通勤隨時查看。

---

## 🛠️ 架構與技術

* **前端**：單頁 HTML5 / CSS3 / JavaScript（託管於 GitHub Pages）。
* **後端**：Google Apps Script (GAS) 部署為 Web App 伺服器端API。
* **資料來源**：[TDX 運輸資料流通服務](https://tdx.transportdata.tw/) (TRA Rail API)。

---

## 🚨 注意事項與維護

1. **TDX Token 授權**：後端 GAS 專案需要在「專案設定 (齒輪) -> 腳本屬性」中設定 `TDX_CLIENT_ID` 與 `TDX_CLIENT_SECRET`。
2. **位置權限**：使用此網頁時，瀏覽器必須開啟「位置存取權限 (GPS)」。
